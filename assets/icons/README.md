# Ícones CEJERA

- `cejera-system.svg`: pictogramas autorais de interface em traço angular, feitos para o ecossistema CEJERA/ROT.
- `cejera-brands.svg`: marcas externas em geometria preservada; o efeito de impressão deslocada é aplicado por `assets/css/icons.css`.

As geometrias de marcas, exceto Telegram, foram normalizadas a partir do projeto [Simple Icons](https://github.com/simple-icons/simple-icons), disponibilizado sob CC0-1.0. O avião do Telegram foi baseado no ativo oficial sem o campo circular. Nomes e marcas continuam pertencendo aos seus respectivos titulares.

Não deformar os logos de terceiros para criar a estética CEJERA. Rotação, cor, sombra e animação devem permanecer na camada CSS.
